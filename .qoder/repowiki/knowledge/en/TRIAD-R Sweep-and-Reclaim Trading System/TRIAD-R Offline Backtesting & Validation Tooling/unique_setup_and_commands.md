Each script invoked directly from the repository root with `python tools/<script>.py`. Key entry points: grid searches (`strategy_optimizer.py`, `aggressive_optimizer.py`, `parameter_grid_search.py`, `extended_grid_search.py`, `multi_pair_grid_search.py`); `tick_signal_builder.py --tick-file ... --output ...` (tick → observed events); `replay_export.py schema|selftest|build`; `triad_validation.py preregister|schema|validate`; `triad_ablation.py preregister|build|validate`. Scripts expect tick files under `validation/HistoryData/` and write findings/markdown/JSON next to the repo root.
