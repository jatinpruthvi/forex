Both EAs require a `triad_red_news.csv` file placed in the MQL5/Files directory containing at least one `COVERAGE` row declaring verified future coverage; without it the EAs halt when `InpRequireNewsCalendar=true`. The production EA additionally requires setting `InpEnableOrderSubmission=true`, configuring `InpAuthorizedLogin`/`InpExpectedAccountServer`/`InpExpectedAccountCurrency`/`InpExpectedAccountLeverage`, and passing all validation gates before live trading. The screen EA is intended for demo accounts only and derives its output filenames from `InpStatusFilePrefix` plus the account login and combo label.
