The module is a flat collection of independent, self-contained research scripts with no shared runtime package — each file is a runnable CLI that reads tab-delimited tick CSVs from `validation/HistoryData/` and writes findings or reports. Two architectural tiers coexist:

- **Strategy exploration tier** (`strategy_orb.py`, `strategy_optimizer.py`, `aggressive_optimizer.py`, `parameter_grid_search.py`, `extended_grid_search.py`, `multi_pair_grid_search.py`, `_validate_4yr.py`) implements Opening Range Breakout (ORB) and sweep/reclaim/displacement signal detectors over EURUSD/GBPUSD/USDJPY London and NY sessions. Each script defines its own `Bar`/`Trade` dataclasses, DST helpers (`london_offset`, `ny_offset`, `lw_to_srv`, `ny_to_srv`), M5/M15 bar builders, ATR(14) computation, lot sizing via fixed risk fraction (0.4% per trade), and a nested-grid loop over parameters like `TARGET_R`, `ORB_BARS`, `STOP_MODE`, `ATR_STOP`, `SWEEP_ATR_MAX`, `RECLAIM_WICK_MIN`, `RECLAIM_BARS`. Results are printed as leaderboards and/or written to markdown findings files.

- **Validation pipeline tier** (`triad_validation.py`, `replay_export.py`, `tick_signal_builder.py`, `triad_ablation.py`) forms a strict producer/consumer chain: `tick_signal_builder.py` converts raw bid/ask ticks into an observed-event CSV; `replay_export.py` validates that event CSV against the frozen V2.1 registry schema and expands it into full calendar coverage replay rows; `triad_validation.py` loads the registry, enforces coverage, applies a conservative fill policy, runs WALK_FORWARD/HOLDOUT simulations with bootstrap confidence bounds, and outputs a JSON report; `triad_ablation.py` layers a preregistered ablation round on top of the same replay rows. Cross-file coupling is limited to explicit imports between these four modules; strategy explorers never import from the validation tier.

All scripts share common conventions: server time is Eightcap UTC+3, London/NY DST is computed via last-Sunday-of-month rules, and instrument specs (`pip`, `tick_value`, `tick_size`) are declared inline per symbol.
