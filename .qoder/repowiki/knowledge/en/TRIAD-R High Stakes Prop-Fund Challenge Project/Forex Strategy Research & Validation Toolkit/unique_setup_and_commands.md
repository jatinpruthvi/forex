Each script is run directly from the repository root with `python tools/<script>.py` (or `python3`). Key entry points include `strategy_optimizer.py` (grid search over ORB variants), `aggressive_optimizer.py` (multi-pair challenge optimizer), `parameter_grid_search.py` / `extended_grid_search.py` / `multi_pair_grid_search.py` (sweep/reclaim parameter sweeps), `tick_signal_builder.py --tick-file ... --output ...` (tick → observed events), `replay_export.py schema|selftest|build`, `triad_validation.py preregister|schema|validate`, and `triad_ablation.py preregister|build|validate`. Scripts expect tick files under `validation/HistoryData/` and write findings/markdown/JSON next to the repo root.
