Tests are run via `python -m unittest discover tests/` (or any individual `test_*.py`). Several tests require the repository root to be accessible so they can locate `MQL5/Experts/*`, `validation/triad_v2_1_registry.json`, and `validation/triad_v2_2_ablation_registry.json`; `git` must be installed because contract tests invoke `git show HEAD:...` and `git status --porcelain` to assert canonical EA and registry files have no local modifications.
